웹/Capacitor 앱(`src/`) 전체의 시각 디자인만 바꿨다. 기능·화면 구성·데이터 흐름·집중도 파이프라인·알림·타이머 로직·Firestore 스키마는 그대로다. `native/`, `android/`, `firestore.rules`, `package.json`, `package-lock.json`은 건드리지 않았다.

## 1. 다섯 줄 방향

- **제품**: 수험생이 공부 시간을 재고, 카메라로 집중 상태를 측정해 기록하고 돌아보는 개인용 학습 계측기.
- **성격**: 정확한, 조용한, 끈질긴.
- **세계**: 밤의 독서실 책상 위 계측기 — 스톱워치, 눈금자, 모눈 기록지, 스탠드 불빛.
- **모먼트**: ① 공부 화면의 얇은 대형 타이머와 그 아래 일일 목표 눈금 ② 홈의 "오늘 공부 시간" — 과목별 구간이 쌓인 측정 테이프 ③ 집중도 다이얼(점수 링 둘레의 20칸 눈금).
- **시그니처**: 계측 눈금 — 30분마다 짧은 눈금, 정시마다 긴 눈금, 현재 값에 앰버 바늘 하나. 시간이 재어지는 곳에만 쓴다(홈 테이프, 공부 화면 목표, 집중도 다이얼, 월간 달력 칸 막대, 일기 점수 10칸, 로고 마크).

미래감은 네온·글로우·글래스·그라디언트가 아니라 "정밀 계측기" 쪽에서 냈다: 얇고 등폭인 큰 숫자, 모노 메타, 눈금, 단일 신호색.

## 3. 패스별 변경 요약

**토큰 레이어 (`src/index.css`)** — 한 곳에서 수백 곳을 바꾸는 지렛대를 먼저 놓았다.
- Tailwind `@theme` 재매핑: `indigo-*`/`purple-*` → 앰버(lamp) 스케일, 장식용 `cyan/sky/pink` → 무채색, `font-black/extrabold/bold` → 600 상한, `tracking-wide*` 축소, `--blur-*` 0.
- 글래스 클래스(`.glass-card`, `.material-chrome`, `.liquid-modal`)는 이름만 남기고 불투명 표면 + 헤어라인으로 뜻을 바꿨다. 컴포넌트 클래스는 `@layer components`로 옮겨 마크업의 유틸리티가 이기게 했다.
- 새 유틸: `.figure`(얇은 등폭 수치), `.meta`(모노 메타), `.fill-ink`, `.fill-accent`, `.seg-active`, `.meter-needle`.

**1. 간격** — 4px 그리드. 카드 패딩 20/24, 사이드바 행 36px·간격 2px, 탭바 56px, 버튼 높이 44-56px로 통일. 임의값(`py-2.5`, `p-10`, `rounded-[2.5rem]`) 정리.

**2. 색** — 그래파이트 무채색 램프(다크 #121213 / 카드 #19191b, 라이트 #f6f6f7 / 카드 #fff), 텍스트 3역할. 액센트는 스탠드 앰버 하나(라이트 글자용 #ad6609, 다크 #e09a35, 바늘 #d98a1c/#e9a23c) — 바늘·선택·핵심 수치(현재 세션, 순공 막대)에만. 주 버튼은 잉크(라이트 검정 / 다크 오프화이트). 배경 블롭·색 그림자·글로우 전부 제거. 의미색(초록/빨강)은 톤 다운해 유지.

**3. 아이콘** — 기존 세트(mdi) 유지, 아웃라인 위주로 통일하고 텍스트 역할색(muted)만 쓰게 했다. 그라디언트 아이콘 타일 13개 → 평범한 18px 아이콘. 이모지 → 아이콘(빈 상태, 함수 호출 칩, 개발자 하이라이트, 차단 화면). `mdi:sparkles`(AI 반짝이) 제거.

**4. 문구** — 홈 인사 헤드라인 → 날짜 제목("11월 9일 월요일"). 격려 문구에서 이모지·느낌표 제거. "Focusing Now / Exit Session / Weekly progress / Select Sub-Item" → "측정 중 / 세션 종료 / 이번 주 / 세부 항목". 변화량에 비교 기준("vs 지난주"). "한 달 간벏 기록" 오타 → "한 달 기록". 느낌표 13곳 제거.

**5. 타입** — 굵기 400/500, 강조 600. 대문자 트래킹 라벨 제거(`uppercase` 73곳). 큰 시간 숫자는 300 굵기 등폭(`.figure`), 메타·날짜·시각은 모노. 11px 미만 글자 136곳 → 11px. 이탤릭 강조 제거. 폰트 파일은 추가하지 않았다(번들 용량 0 증가, 기존 Pretendard → 시스템 폰트 스택 유지).

**6. 레이아웃** — 섹션 순서 유지. 사이드바: 떠 있는 둥근 패널 → 화면에 붙은 256px 크롬. 모바일 탭바: 떠 있는 알약 → 하단 고정 바 + 활성 탭 위 앰버 바늘. 홈 히어로: 가운데 정렬 그라디언트 숫자 → 좌측 정렬 대형 수치 + 측정 테이프 + 과목 목록. 공부 화면: 헤더·본문·푸터를 max-w-3xl 한 축에 정렬, 목표 눈금을 큰 숫자 바로 아래로.

**7. 디테일** — 반경 체계(컨트롤 8-10, 카드 16, 패널·모달 20). 세그먼트 선택은 액센트 채움 대신 한 단계 올라온 표면(`.seg-active`). 점수 선택(일기·세션 평가)은 "점수까지 채움 + 고른 칸만 앰버"로 눈금처럼. 차트: 총합=무채색, 순공=앰버 한 시리즈, 축은 모노·무선. 파이 차트 → 순위 목록 + 가는 막대(1위만 앰버). 연간 히트맵 → 앰버 5단계. 월간 달력 칸마다 2px 계측 막대. 로고: 그라디언트 차트 이미지 → 평면 마크(눈금 3개 + 앰버 바늘, `BrandMark`).

**8. 비주얼** — 장식 블롭·글로우·광택 스윕 제거. 이미지 생성은 쓰지 않았다(앱 화면이라 제품 자체 — 타이머·테이프·다이얼·차트 — 가 모먼트). 새 컴포넌트 `MeterScale`(눈금) 하나로 시그니처를 구현.

**9. 모션** — 로고 둥실·Founder 광택·차단 화면 펄스 등 루프 제거. `materialize`의 블러 애니메이션 → 8px 상승 + 페이드. 눌림 스케일 최소 0.96, 호버 리프트 제거(`Pressable`), 선택 시 커지는 스프링 제거. `transition-all` 40곳 → 색·배경·테두리·투명도·변형만. 곡선 하나 `cubic-bezier(0.22, 1, 0.36, 1)`. 로딩 스켈레톤 펄스는 실제 대기 상태라 유지.

## 4. 기능 불변 근거

- 변경은 className·인라인 스타일·문구·마크업 배치에 한정. 상태·이벤트 핸들러·DB 호출·네이티브 브리지 호출은 손대지 않았다(전역 치환은 클래스 토큰 정규식으로만, 치환 후 비-className 변경 줄을 diff로 걸러 확인).
- 문구가 바뀐 곳은 UI 라벨뿐이고, 저장되는 데이터 키·값은 그대로다. 예외: Gemini 채팅의 시스템 메시지 접두어 `❌ `→`오류: `, `> 💡`→`> 참고:` (표시용 문자열).
- 버전(`1.8.1`)은 올리지 않았다 — `package.json`이 원래 체크아웃에서 미커밋 수정 중이라 충돌을 피했다. 그래서 업데이트 후 체인지로그 팝업도 뜨지 않는다.

1. 원래 체크아웃(또는 아무 클론)에서 `git pull` 후 `git revert <개편 커밋 SHA>` → `git push origin main`. Actions가 이전 디자인으로 다시 배포한다.

## 9. 남은 이슈

- **앱 아이콘·스플래시·PWA 아이콘은 그대로**(보라 그라디언트 차트). `android/` 리소스와 `public/*.png`는 원래 체크아웃의 미커밋 android 변경과 겹칠 수 있어 건드리지 않았다. 새 `BrandMark`로 아이콘을 다시 만드는 것이 다음 작업.
- **원래 체크아웃의 로컬 `main`은 뒤처져 있다.** 미커밋 파일(`android/…`, `firestore.rules`, `package*.json`, `src/lib/backup.ts`)과 개편 커밋은 겹치는 파일이 없으므로 그 체크아웃에서 `git pull`이 그대로 fast-forward 된다.
- 원래 체크아웃의 미커밋 보안 수정(@capacitor 8.4.3, 백업 키 제거, Firestore 규칙)은 이번 배포·APK에 **포함되지 않았다**. `firestore.rules`는 배포하지 않았다.
- `npm run lint` 기존 오류 36건.
- 개발자 페이지 소개문에 "Liquid Glass 디자인 시스템" 문구가 남아 있다(사용자 본인 글이라 유지). 사이드바 "Made by SeungHyeok"·크레딧 "Yoo Seung Hyeok" 표기도 기존 그대로 — 전역 규칙(영문명 Hyeok Yoo)에 맞출지 결정 필요.
- 관리자(Admin)·개발자 도구·RoomPanel은 전역 토큰과 일괄 치환만 적용했다(세밀 패스는 홈·공부·기록·편집·설정·모달 위주).
- 한글이 섞인 문자열에 모노 폰트를 쓴 곳은 시스템 한글 폰트로 대체돼 자간이 살짝 넓다. 숫자 전용 위치에만 모노를 남겼지만 몇 곳("목표 8h 0m")은 섞여 있다.

- **색**: 맑은 블루 단색(#2f6fed, 다크 #5b94ff)을 주색으로 되살림. 주 버튼·선택 칩·활성 내비·바늘·눈금 채움·차트가 모두 블루 단계. 표면은 살짝 푸른 밝은 램프(라이트 #f2f5fa) / 남색 잉크(다크 #0c111a). 그라디언트·글로우는 여전히 없음.
- **반경**: 카드 24, 입력 14, 모달 28, 버튼·칩·세그먼트 선택은 알약. Tailwind `rounded-*` 단계 전체를 한 단계씩 키움(lg 14, xl 18, 2xl 22, 3xl 28).
- **사이드바**: 폭 256/288px, 행 48px, 글자 16px, 아이콘 22px, 활성 항목은 블루 알약. 모바일 탭바도 활성 아이콘 뒤 블루 알약.
- **넓은 화면**: 본문 최대 폭 1024 → 1480px. 홈은 폭 1280px 이상에서 2단(왼쪽 오늘 측정값·시작·일기 / 오른쪽 레일 D-day·체크리스트·회고), 좁은 화면 순서는 그대로. 설정은 2단 흐름. 기록은 폭 제한 해제.
- **공부 화면**: 폭 1024px 이상에서 2열(왼쪽 타이머·눈금·지표 / 오른쪽 재생·주차장 버튼과 방·집중도 패널). 큰 숫자는 칸 너비에 맞춰 커짐(container query). 아이패드 가로 "컴팩트 모드"는 2열이 세로 여유를 만들어 1024px 미만에만 적용하도록 좁힘. 과목 선택 알약은 블루.
